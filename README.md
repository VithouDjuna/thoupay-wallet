# ThouPay Wallet

[![Backend CI](https://github.com/VithouDjuna/thoupay-wallet/actions/workflows/backend-ci.yml/badge.svg?branch=main)](https://github.com/VithouDjuna/thoupay-wallet/actions/workflows/backend-ci.yml)

A web-based digital wallet (top-up, transfers, QR payments) with an admin back office.

| Folder | What's inside |
|---|---|
| `backend/` | Spring Boot API |
| `frontend/` | React + TypeScript web app |
| `infra/` | Local platform (Docker Compose, Kubernetes) |
| `docs/` | Product, architecture, tickets, runbooks |
